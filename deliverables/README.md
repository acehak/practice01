# 결 · 상담 프로그램 받기

`gyeol-consult-v2.zip` 파일을 다운로드한 후 압축을 풀고 `gyeol-consult.html`을 Chrome 또는 Edge에서 열어 주세요. 별도 설치나 서버가 필요하지 않습니다.

처음에는 모두 미평가 상태입니다. **예시 상담 보기**는 가상의 점수·소견을 불러오며, **새 상담 시작**은 현재 상담 내용을 초기화합니다.

상담 내용은 자동 저장되지 않습니다. 창을 닫거나 새로고침하기 전에 **상담 요약**에서 복사 또는 인쇄/PDF로 기록하세요.

이 폴더는 파일 전달을 위해 준비한 결과물입니다. GitHub에 게시됐는지는 별도로 확인해야 하며, 파일을 생성한 것만으로 원격 다운로드 링크가 만들어지는 것은 아닙니다.
