# 결 · 피부 상담 워크스페이스

의료진이 환자와 얼굴 그림을 보며 고민을 평가하고 기본·확장 상담 플랜을 구성하는 한국어 웹 앱입니다.

## 바로 사용

`npm run build`로 만든 `dist/gyeol-consult.html`을 브라우저에서 열면 설치나 서버 없이 사용할 수 있습니다. 처음에는 모든 항목이 미평가입니다. **예시 상담 보기**로 가상 상담 흐름을 확인하세요. 공유용 HTML·ZIP은 `npm run package:app`으로 `deliverables/`에 생성합니다(패키징에는 Python 3 필요).

클라우드 작업공간의 파일 경로나 `sandbox:` 링크는 이 채팅에서 다운로드를 보장하지 않습니다. 실제 전달은 저장소에 결과물을 게시하는 등 지원되는 경로가 필요하며, 원격 게시 여부를 별도로 확인해야 합니다.

## 개발 및 검증

Node.js 20.19 이상 또는 22.12 이상을 사용합니다. 현재 환경은 Node.js 24입니다.

```sh
cd /workspace/practice01
npm ci --no-audit --no-fund
npm run dev
```

```sh
npm test
npm run build
```

## 상담 흐름

1. 얼굴 그림이나 부위 버튼으로 관련 평가 항목을 찾습니다. 부위 선택은 필터이며, 점수와 추천은 항목 단위입니다.
2. 9개 항목을 구체적인 관찰 기준에 따라 0–4점으로 기록합니다. **미평가와 0점**은 구분됩니다.
3. 항목별 **진찰 소견**으로 원인·유형을 구분하고 환자의 피부 반응, 회복 여유, 시술 선호를 입력합니다. 별표는 환자가 원하는 상담 우선순위입니다.
4. 기본 플랜은 우선 고려할 평가·관리·시술 후보, 확장 플랜은 경과 확인 후 고려할 추가·대체 후보입니다. 의사가 후보의 적합성을 검토합니다.
5. **상담 요약**에서 평가자를 입력하고 내용을 복사하거나 인쇄/PDF로 남깁니다. **새 상담 시작**은 현재 입력을 초기화합니다.

## 평가 및 추천 범위

- 잡티·색소, 붉은기, 활성 여드름, 흉터·모공, 탄력·잔주름, 처짐·리프팅, 윤곽, 볼륨, 장벽·건조·기타
- 입력된 0점에는 추천하지 않으며 1점 이상은 기본, 2점 이상은 확장 후보를 검토합니다. 이는 자체 상담 규칙이며 검증된 진단 척도나 치료 강도 기준이 아닙니다.
- 같은 점수라도 표정 주름·정적 잔주름·탄력 저하, 근육·지방·골격 등 진찰 소견에 따라 시술 후보가 달라집니다. 원인이 미확인인 경우 원인 구분을 우선 안내합니다.
- 처짐은 의사가 확인한 원인에 따른 병원 상담 기준으로 분리했습니다: **근막층 처짐 → 울쎄라피 프라임**, **유지인대 지지 저하 → 티타늄**, **지방 볼륨 과다 → 온다**. 원인이 미확인이면 장비 후보를 연결하지 않습니다. **피부 탄력 저하 → 써마지 FLX**는 탄력·잔주름 항목에서만 검토합니다.
- 이 원인별 연결은 병원에서 설정한 상담 매핑이며, 장비가 특정 해부학적 구조를 치료하는 기전·효과를 확정하거나 보편적인 치료 지침을 제시하지 않습니다. 복합 원인·부위별 적용은 의료진이 따로 판단합니다.
- 비침습 및 회복 부담 최소화 선호에 따라 주입·미세침 후보를 보류합니다. 민감 반응 이력과 현재 활동성 염증을 구분합니다.
- 임신·수유, 최근 시술, 현재 염증 또는 심한 활성 여드름은 관련 후보를 우선 확인·보류 목록으로 이동합니다. 이 세 가지 확인 항목이 전체 금기·적응증 문진을 대신하지는 않습니다.
- 기본·확장 플랜은 모두 병합하는 패키지가 아닙니다. 시술 부위·제품·모드·용량·강도·횟수·효과·가격을 자동 결정하지 않습니다.

## 병원 시술 라이브러리

울쎄라피 프라임, 써마지 FLX, 소프웨이브, 온다, 티타늄, 포텐자, 필러, 보톡스, 리쥬란, 리투오, 고우리, 힐로웨이브, 레디어스를 반영했습니다. 색소·혈관 전용 장비는 제공된 목록에 없어 별도 옵션 확인으로 표시합니다.

현재 버전은 **얼굴 상담**입니다. 바디·리프팅 필러는 각 부위와 해부학적 적응증을 별도로 평가해야 합니다. 시술 후보와 관찰 기준은 의료진 검토를 전제로 하며 실제 사용 전 병원 기준에 맞게 조정할 수 있습니다. 추천 데이터와 규칙은 `src/domain.js`에 있습니다.

상담 내용은 브라우저 메모리에서만 유지되며 서버 전송·자동 저장·환자 기록 관리 기능은 없습니다. 새로고침하거나 화면을 닫으면 초기화됩니다. 마크뷰 연계는 이번 버전에서 제외했습니다.
